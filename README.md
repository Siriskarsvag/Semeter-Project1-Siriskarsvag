Semester project for AW25. Project was to build an informational online page for a local scienece museum. 

## Description

The assignment was to build a informational online webpage, meant to engange children and their families in science at a local museum. Project executed by using HTML and CSS. The project was also meant to be planned and managed using GitHub Projects. 

The webpage featured:

- A Home page, showing news and upcoming activeties
- An "about us" page
- A page showing the museums exhibitions
- A page showing museum activities
- A page for audience to interact, "get involved"
- And a contact page

- CSS
